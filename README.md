
# 🛒 EcomShop SQL Project

A beginner-friendly MySQL project that simulates an **E-Commerce Shopping Management System**. This project demonstrates the complete database development process—from creating a database and tables to inserting sample data and performing business analysis using SQL queries.



## 📌 Project Overview

The **EcomShop** database is designed to manage an online shopping platform by storing information about:

- Customers
- Products
- Orders
- Order Items
- Payments

The project showcases fundamental SQL concepts and how they can be applied to solve real-world business problems.



## 🎯 Learning Objectives

Through this project, I learned how to:

- Create a database in MySQL
- Design relational database tables
- Define Primary Keys and Foreign Keys
- Insert sample data into tables
- Retrieve data using SQL queries
- Perform data analysis using SQL
- Work with multiple table relationships using JOINs
- Use aggregate functions to generate business insights



## 🛠️ Technologies Used

- MySQL 8.0

- SQL

## 📚 SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT INTO
- PRIMARY KEY
- FOREIGN KEY
- INNER JOIN
- GROUP BY
- ORDER BY
- Aggregate Functions
  - SUM()
  - COUNT()
  - AVG()

This project includes SQL queries to answer business questions such as:

1) What Is Total Revenue ?

2) Revenue By Product

3) Top Customers By Spend

4) Best Selling Products

5) Cancelled Orders Count

6) Which product is the most expensive ?
